## KiMi Code

### 环境配置

* 官网：https://www.kimi.com/code
* 安装方法：
  * Linux：`curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash`
  * Windows PowerShell: `irm https://code.kimi.com/kimi-code/install.ps1 | iex`
* 登录：`kimi`后`/login`登录，然后`/model`选择模型
* VSCode：安装`KiMi Code`，然后点击KiMi按钮登录
  * 打开kimi配置，Autosave:True，Yolo Mode:True

### 命令

* `kimi --yolo`：全权限打开
* `kimi -p "帮我看一下这个项目的目录结构"`：单轮对话
* `kimi -c`：继续上次对话
* `/new`：开启新对话
* `/sessions，/resume`：浏览和选择历史对话
* `/title, /rename`：当前会话命名
* `/compact`：压缩上下文
* `/export`：保存会话
* `/help`：显示帮助命令
* `/goal`：目标模式，设置目标直到完成
* `/plan`: 计划模式
* `@`：引用文件或目录

### 按键

* `Esc`：中断流式输出
* `Ctrl-C`：中断输出
* `Shift-Tab`：切换Plan模式
* `Ctrl-S`：中途插入消息，无需等待
* `Ctrl-O`：折叠/展开工具输出和压缩摘要

### 目录

* 所有会话默认保存在`~/.kimi-code/sessions/`
* `~/.kimi-code/config.toml`：配置文件
* MCP配置在`~/.kimi-code/mcp.json`和当前项目`.kimi-code/mcp.json`
* SKILLS配置在`~/.kimi-code/skills/`和当前项目`.agents/skills/`或者`.kimi-code/skills/`

### API调用

在Claude Code中配置如下(`~/.claude/settings.json`)：

```shell
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的API Key",
    "ANTHROPIC_BASE_URL": "https://api.kimi.com/coding/",
    "ANTHROPIC_MODEL": "k3" #kimi-for-coding,
    "CLAUDE_CODE_SUBAGENT_MODEL":"k3", # "k3[1m]"
    "CLAUDE_CODE_EFFORT_LEVEL":"max", # low,high,max
    "CLAUDE_CODE_MAX_CONTEXT_TOKENS":"262144",
    "CLAUDE_CODE_ATUO_COMPACT_WINDOW":"250000",
    "CLAUDE_CODE_ATTRIBUTION_HEADER":"0"
  }
```

在Copilot CLI配置如下：

```shell
# linux
export COPILOT_PROVIDER_BASE_URL=https://api.kimi.com/coding/v1
export COPILOT_PROVIDER_TYPE=openai
export COPILOT_PROVIDER_API_KEY=你的API Key
export COPILOT_MODEL=kimi-for-coding # kimi-for-coding-highspeed
```
